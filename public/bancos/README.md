# Logotipos bancários — Nexus Finanças

Este diretório armazena logotipos de instituições financeiras.

Padrão de arquivos:
- Formato preferencial: SVG ou PNG
- Nome do arquivo: código bancário com três dígitos
- Exemplo: 260.svg para o Nubank

Os logotipos devem ser obtidos de fontes confiáveis e
utilizados respeitando a identidade visual das instituições.

Quando não existir logotipo disponível, a interface deverá
apresentar o ícone bancário padrão.
